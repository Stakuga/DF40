# Explainable Deepfake Detection Framework
**Human-AI collaboration for deepfake detection via explainable image classification**

## Overview
We presently establish the code used to implement the explainable deepfake detection framework utilised in the above study. This framework classifies facial portraits as either real or deepfake, and can provide accompanying explanations to users. This is done to facilitate human-AI collaboration, given the necessity of understandable mechanisms in downstream deepfake detection applications. 

## Technical Configuration
This framework consists of two key components.

1. The deepfake detection model: 
  - We extend the CLIP-large classification model as our deepfake classifier. 
  - This model is pretrained on the DF40 benchmark dataset, hence our extension of the repository as a fork.

2. The explainability layer: 
  - We implement textual, visual and textual-visual explanations on top of the pretrained classifier. 
  - The textual explanations are generated by Gemini 2.5 Pro.
  - The visual explanations are generated using Score-CAM heatmaps.
  - The textual-visual explanations are a combination of LLM-generated text conditioned on Score-CAM heatmaps.

## Findings
This detection framework was evaluated in practical use with 40 human participants. We observed a significant increase to collaborative accuracy and user confidence when participants were given only textual explanations. No effects were observed in conjunction with the inclusion of visual explanations.
